# Подово отопление – калкулатор

Калкулатор за водно подово отопление: метри тръба, кръгове, колектор, разпознаване на чертежи и отчет в PDF.

**Отвори:** https://velislav1.github.io/podovo-otoplenie/

- Работи на компютър, таблет и телефон; инсталира се като приложение („Инсталирай“ / „Добави към началния екран“).
- Работи и без интернет след първото отваряне.
- Обектите, чертежите и API ключът се пазят само в браузъра на устройството – нищо не се качва в интернет.
